# Paper Example 5: Mathematical Ledger

## Sources

Main article PDF pages 26-28 (journal pages 382-384), Example 5, Tables II-III. The
example reuses Example 3 and Supplement Section 3.3.

## Target and tax multiplicity

Aggregate endowment of commodity 0 is `0.4`. A 30 percent reduction means
consumption/absorption `0.12` and emissions `C=0.28`.

Table II reports one tax rate on each equilibrium branch that produces 30 percent
reduction:

```text
tau=0.011448:   reductions (30.00,37.49,41.97)
tau=0.00951705: reductions (24.95,30.00,36.59)
tau=0.0075832:  reductions (19.89,23.41,30.00)
```

Thus no listed tax rate guarantees the target because each has three equilibria.

## Quota economy

The quota economy has the same agents, endowments, consumption sets, and utilities,
but only a government firm `Y_0={0}`. It distributes quota revenue equally. Set

```text
m=-0.28,
Z(m)={m}x{0}^2.
```

Table III reports three quota equilibria, all with 30 percent reduction, and quota
prices `0.011448`, `0.00951705`, and `0.0075832` in the Example 3 goods-sum price
convention. Core signed-L1 quota prices are each table value divided by `1+value`.
